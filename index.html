Instalar App y Uso en GitHub

Compatible con Pantallas Android, Windows, Mac y Chromebook

📲 Instalación rápida en este dispositivo Crea un acceso directo en el escritorio o pantalla de inicio como app independiente.

1️⃣ Publicar en GitHub Pages (para abrir en cualquier clase)

  1. Crea un repositorio público en GitHub (ej. porcentajes-primaria).
  2. Sube este archivo renombrado como index.html.
  3. Ve a Settings → Pages, elige la rama main y guarda.
  4. Obtendrás un enlace web listo para abrir en los ordenadores y pantallas digitales del colegio.

2️⃣ Descargar e instalar en modo Aplicación (sin barra del navegador)

  • En Pantalla Digital Android / Tablet: Abre el enlace de GitHub Pages en Chrome, pulsa los 3 puntos (⋮) y selecciona «Instalar aplicación» o «Añadir a pantalla de inicio».
  • En Ordenador (Chrome / Edge): Pulsa el icono de instalar ⊕ en la barra de direcciones o guarda el archivo index.html para abrirlo incluso sin Internet.
